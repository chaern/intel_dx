# LeRobot · SmolVLA 로봇 모방학습 실습

리더·팔로워 로봇팔과 카메라 2대로 시연 데이터를 수집하고, LeRobot의 SmolVLA 정책을 로컬 GPU에서 미세학습했습니다.

## 시연 데이터

- Windows 카메라 영상을 브리지로 WSL에 전달하고 Rerun에서 영상과 로봇 상태를 확인했습니다.
- 카메라·관절 데이터의 저장과 재읽기, 에피소드 추가 저장 및 녹화 취소를 확인했습니다.
- 첫 학습 데이터는 **시연 10개, 7,840프레임, 30fps**입니다. 에피소드 단위로 학습 8개(6,529프레임)와 검증 2개(1,311프레임)를 분리했습니다.

## 학습 결과

`lerobot/smolvla_base`를 WSL의 CUDA 환경에서 BF16으로 2,000스텝 미세학습했습니다. 배치 크기는 4였고, 500스텝마다 체크포인트를 저장했습니다.

| 스텝 | 500 | 1,000 | 1,500 | 2,000 |
| --- | ---: | ---: | ---: | ---: |
| 검증 loss | 0.2274 | 0.1656 | 0.0997 | 0.0980 |

검증 loss는 최초 기록인 500스텝 대비 **56.9% 감소**했습니다. 이 값은 분리된 시연 데이터에서의 동작 예측 오차입니다. 실물 과제의 반복 성공률은 기록에서 확인하지 못했습니다.

## 문제 해결과 구동 확인

| 문제 | 조치와 확인 결과 |
| --- | --- |
| 모델과 시연 데이터의 카메라 입력 불일치 | 실행 설정을 실제 두 카메라 입력에 맞췄습니다. |
| FP16 GradScaler와 BF16 gradient 간 오류 | CUDA autocast를 BF16으로 지정하고 GradScaler 없이 학습을 완료했습니다. |
| 동기 추론 중 211~261ms 제어 정지 | RTC 비동기 추론 적용 후, 모터를 구동하지 않는 시험에서 초기 구간 이후 270개 행동을 큐 공백 없이 공급했습니다. |
| 실물 구동 확인 | RTC 설정으로 60초 구동 후 정상 종료를 확인했습니다. |

## 후속 실험

시연을 11개로 늘려 10,000스텝 학습을 완료하고 체크포인트를 실행 설정에 연결했습니다. 공통 조건의 평가 수치와 반복 실물 시험 결과가 없어 두 모델의 성능 차이는 확인하지 못했습니다.
