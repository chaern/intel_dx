# Intel DX 실습 포트폴리오

인텔 AI 융합 DX 과정에서 다룬 산업 자동화, 로봇 제어, 영상 처리, Python 실습 자료를 모았습니다.

## 대표 프로젝트

| 프로젝트 | 내용 | 자료 |

| **Factory I/O 작업물 분류** | 비전 센서의 디지털 출력과 PLC를 연결해 가상 공정에서 금속·비금속 작업물을 분류하는 실습 | [센서·입출력 메모](PLC/1007/sensor.txt) |
| **Indy7 로봇 이송·적재** | 격자 위치를 계산해 물체를 옮기고 적재하는 실습과 PLC 워드 명령 처리 예제 | [격자 적재](robot/0908/25repeat.py) · [PLC 명령 처리](robot/1002/plc_slide.py) |
| **MELSEC-Q 서보 위치결정** | 원점복귀, JOG 운전, 위치 티칭 실습 | [서보 실습 문서](PLC/0901/README.md) |
| **OpenCV 영상 처리** | 이미지 변환, 이진화, 블러, 엣지 검출, 카메라 입력 실습 | [영상 처리 자료](AI_Edge/1015/) |
| **Intel Geti 여행 준비물 객체 탐지** | 준비물 7종의 라벨링, 학습 회차별 점수와 새 이미지 테스트 기록 | [Geti 실습](geti-travel-item-detection/README.md) |
| **LeRobot·SmolVLA 모방학습** | 카메라 2대를 이용한 시연 수집, 정책 미세학습과 로봇 구동 검증 | [LeRobot 실습](lerobot-smolvla-practice/README.md) |
